# Experiment design: Topic Across many independently generated and prospectively defined 48-seed blocks, what are the distributions of selected-rule uplift, held-out retention, selected-rule identity, eligible sample size, and threshold-decision rate? _(auto-enqueued follow-up from topic-can-a-feasibility-study-report-every-attem)_

**Hypothesis:** For a deterministic sequence of 1,000 independently generated seeds analyzed as consecutive 48-seed windows, stride-1 overlapping windows will yield lag-1 autocorrelation above 0.90 for selected-rule uplift and above 0.80 for threshold decisions, whereas disjoint 48-seed blocks will have absolute lag-1 autocorrelation below 0.10 for both outcomes; treating the overlapping windows as independent will underestimate the Monte Carlo standard error of the threshold-decision rate by at least a factor of three.

## Summary
Simulate 1,000 independent prospective seed-level experiments, compare statistics from 953 overlapping stride-1 windows with 20 disjoint 48-seed blocks, and quantify autocorrelation and Monte Carlo standard-error inflation.

## Protocol
1. Use Python 3 with numpy, pandas, and matplotlib only. Set MASTER_SEED = 20250308 and create 1,000 independent seed streams with numpy.random.SeedSequence(MASTER_SEED).spawn(1000), using one spawned stream per prospective seed-level experiment.
2. For each seed s from 0 through 999, generate two independent synthetic splits, development and held-out, each containing exactly 256 observations. For each observation generate six independent binary features X1,...,X6 with P(Xj=1)=0.5, randomized treatment T with P(T=1)=0.5, noise epsilon distributed N(0,1), individual treatment effect tau = 0.15 + 0.10*X1, and outcome Y = T*tau + epsilon. Generate the development split first and the held-out split second from the seed's RNG stream.
3. Prospectively define six candidate rules before analyzing any data: R1={X1=1}, R2={X2=1}, ..., R6={X6=1}. For every seed, split, and rule, store sufficient statistics: eligible count, eligible treated count and outcome sum, and eligible control count and outcome sum. Do not select rules within individual seeds.
4. Define a block-level rule uplift as mean(Y | eligible,T=1) minus mean(Y | eligible,T=0), computed after pooling the sufficient statistics across all seeds in that block. A rule is eligible for selection only if its pooled development data contain at least 500 treated and 500 control observations; this should normally hold for every rule in a 48-seed block. If no rule is eligible, mark all block outputs missing, although this event is not expected.
5. Construct 953 overlapping windows W_t={t,...,t+47} for t=0,...,952. Separately construct 20 disjoint prospective blocks B_b={48b,...,48b+47} for b=0,...,19, discarding seeds 960 through 999 only for the disjoint analysis.
6. In each window or block, select the eligible rule with the largest pooled development uplift. Resolve exact ties by choosing the lowest-numbered rule. Record: selected-rule identity; selected development uplift U_dev; selected rule's pooled development eligible count N_eligible; held-out uplift U_hold obtained by applying that already-selected rule to the corresponding pooled held-out observations; held-out retention H=U_hold/U_dev; and threshold decision D=1 if U_dev >= 0.25 and D=0 otherwise. Never use held-out data for rule selection or threshold decisions.
7. For both the 953 overlapping windows and 20 disjoint blocks, summarize U_dev, H, and N_eligible by count, mean, sample standard deviation, minimum, 5th, 25th, 50th, 75th, and 95th percentiles, and maximum. Report rule-identity counts and proportions for R1 through R6, the threshold-decision count, and threshold-decision rate.
8. For a numeric series z_1,...,z_m, define lag-1 autocorrelation as numpy.corrcoef(z[:-1],z[1:])[0,1]. Compute this separately for U_dev and D in the overlapping sequence and in the disjoint sequence. If either side of a correlation has zero variance, report the correlation as undefined and treat the associated hypothesis condition as failed.
9. Compute the naive Monte Carlo standard error for the overlapping threshold-decision rate as SE_naive=sqrt(p_overlap*(1-p_overlap)/953), where p_overlap is the mean of the 953 overlapping decisions.
10. Estimate a dependence-aware Monte Carlo standard error by nonparametric bootstrap of the independent seed-level records. Use numpy.random.default_rng(8675309), B=2000 bootstrap replicates, and in each replicate sample 1,000 indices with replacement from 0,...,999. Preserve each sampled seed's complete development and held-out sufficient-statistic record, place sampled records in draw order, reconstruct all 953 stride-1 48-record windows, repeat development rule selection and threshold decisions exactly as above, and save that replicate's mean decision. Define SE_bootstrap as the sample standard deviation with ddof=1 of the 2,000 bootstrap decision rates. Compute the underestimation factor F=SE_bootstrap/SE_naive; if SE_naive is zero, set F to infinity only when SE_bootstrap is positive, otherwise mark it undefined.
11. Save all block-level records to block_results.csv with a column identifying overlapping versus disjoint analysis. Save scalar summaries, autocorrelations, decision rates, standard errors, the ratio F, and each pass/fail condition to metrics.json.

Create key_results.png at 180 DPI as a 2-by-2 figure: panel A plots overlapping U_dev against window start with a horizontal line at 0.25; panel B plots overlapping D against window start using a step plot; panel C is a grouped bar chart of the four lag-1 autocorrelations with horizontal reference lines at 0.90, 0.80, 0.10, and -0.10; panel D compares SE_naive and SE_bootstrap as bars and annotates their ratio F. Use fixed axis labels and no randomized plotting operations.
13. Declare the hypothesis supported only if all five preregistered conditions hold simultaneously: overlapping uplift autocorrelation > 0.90; overlapping decision autocorrelation > 0.80; absolute disjoint uplift autocorrelation < 0.10; absolute disjoint decision autocorrelation < 0.10; and F >= 3.00. Otherwise declare it refuted. Do not round values before applying thresholds; display at least six decimal places in metrics.json.

## Metrics
- Overlapping selected-rule uplift lag-1 autocorrelation: Pearson correlation between U_dev values in adjacent members of the 953-window stride-1 sequence; required to exceed 0.90.
- Overlapping threshold-decision lag-1 autocorrelation: Pearson correlation between adjacent binary D values in the 953-window sequence; required to exceed 0.80.
- Disjoint selected-rule uplift lag-1 autocorrelation: Pearson correlation between adjacent U_dev values across the 20 disjoint blocks; its absolute value must be below 0.10.
- Disjoint threshold-decision lag-1 autocorrelation: Pearson correlation between adjacent binary D values across the 20 disjoint blocks; its absolute value must be below 0.10.
- Monte Carlo standard-error underestimation factor: SE_bootstrap divided by sqrt(p_overlap*(1-p_overlap)/953), where SE_bootstrap is the standard deviation of 2,000 seed-record bootstrap estimates; required to be at least 3.00.
- Selected-rule uplift distribution: count, mean, sample standard deviation, minimum, 5th, 25th, 50th, 75th, and 95th percentiles, and maximum of U_dev, reported separately for overlapping and disjoint blocks.
- Held-out retention distribution: the same summaries for H=U_hold/U_dev, reported separately for overlapping and disjoint blocks.
- Selected-rule identity distribution: counts and proportions of selected R1 through R6 under each block construction.
- Eligible sample-size distribution: the same summaries for the selected rule's pooled development eligible count.
- Threshold-decision rate: mean of D under each block construction, with the overlapping rate also accompanied by naive and bootstrap Monte Carlo standard errors.
