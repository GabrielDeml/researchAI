# Experiment design: Topic In real model-selection pipelines, how frequently does first-encountered tie-breaking change only an internal identifier, an optimizer-family conclusion, or held-out performance? _(auto-enqueued follow-up from topic-can-the-120-split-analysis-be-repeated-on)_

**Hypothesis:** For 40 deterministic tie fixtures in which one family contributes eight validation-tied configuration identifiers and a second family contributes one, 1,000 seeded uniform random candidate orders per fixture will select the eight-identifier family in 85% to 92% of orders; after collapsing semantically identical configurations and sampling tied families uniformly, its selection frequency will fall to 47% to 53%.

## Summary
Construct 40 synthetic exact-validation-tie fixtures and compare first-encountered selection over nine identifiers with duplicate-collapsed, family-uniform selection across 1,000 deterministic random orders per fixture.

## Protocol
1. Use Python 3.11 or later with numpy, pandas, and matplotlib. Set the global master seed metadata to 20250308 and use numpy.random.default_rng with the per-step seeds specified below. Do not use network data.
2. Generate 40 binary-classification fixtures indexed f=0,...,39. Each fixture has 100 validation examples and 200 held-out examples. Use RNG seed 10000+f. Generate each label vector independently as integers uniformly sampled from {0,1}.
3. In every fixture create two optimizer families named A and B. Family A has eight configuration identifiers A_0 through A_7, all with semantic signature A_semantic_0. Family B has one identifier B_0 with semantic signature B_semantic_0. The eight A identifiers must reference identical validation and held-out prediction arrays; only their identifier strings differ.
4. Construct validation predictions with exact accuracy 0.80 for both semantic configurations. Draw one random permutation of the 100 validation indices using the fixture RNG. Family A predictions equal the labels except that indices permutation[0:20] are flipped. Family B predictions equal the labels except that indices permutation[20:40] are flipped. For binary labels, flip with 1-label. Assert that all eight A identifiers have byte-for-byte identical predictions, A and B predictions differ, and every candidate's validation accuracy is exactly 80/100.
5. Construct held-out predictions so that family A always has accuracy 0.80 and family B has a fixture-stratified accuracy. For fixtures 0-9 set B accuracy to 0.70; for 10-19 set it to 0.78; for 20-29 set it to 0.82; and for 30-39 set it to 0.90. Thus A-minus-B held-out gaps are +0.10, +0.02, -0.02, and -0.10 in four equal strata. Draw a fresh permutation of the 200 held-out indices. Flip permutation[0:40] for A. For B, flip the last 60, 44, 36, or 20 permutation indices, respectively. Assert all intended accuracies exactly.
6. Implement the first-encountered baseline exactly as follows. For each fixture, define the candidate list [A_0,A_1,...,A_7,B_0]. Initialize an RNG with seed 20000+f. For each of 1,000 repetitions, obtain a fresh uniform permutation of all nine candidates, scan it from first to last, initialize best_score to negative infinity, and replace the incumbent only when candidate_validation_accuracy > best_score. Do not replace on equality. Record the selected identifier, family, validation accuracy, and held-out accuracy. This is equivalent to selecting the first candidate in the random order because all validation scores tie, but the scan must still be implemented to test actual tie behavior.
7. Implement the comparison procedure independently for each fixture using RNG seed 30000+f. First collapse candidates by semantic signature, verifying that A_0 through A_7 form one semantic configuration. Determine the optimizer families attaining the maximum validation accuracy after collapse; both A and B must qualify. For each of 1,000 repetitions, sample one qualifying family uniformly with rng.choice over the sorted list [A,B]. Use A_0 or B_0 as the canonical reporting identifier after the family is selected. Record family, validation accuracy, and held-out accuracy.
8. Combine the 40,000 records from each method. Compute the pooled family-A selection frequency separately for the baseline and comparison. Also compute each frequency separately for every fixture. The theoretical value is 56/81, approximately 0.69136.

## Metrics
- Baseline family-A selection frequency: number of first-encountered runs selecting any A identifier divided by 40,000.
- Collapsed family-uniform family-A selection frequency: number of comparison runs selecting family A divided by 40,000.
- Grid-cardinality effect: baseline family-A frequency minus collapsed family-A frequency; support requires at least 0.32.
- Selection odds ratio: odds of selecting A under first-encountered selection divided by the corresponding odds under family-uniform selection.
- Per-fixture family-A frequencies: A selections divided by 1,000 for each fixture and method.
- Identifier-only instability: p_A squared minus the sum of squared selection frequencies for A_0 through A_7, representing the probability that two independent baseline draws select different A identifiers but the same family.
- Held-out performance shift: within each fixture, mean selected held-out accuracy under the baseline minus that under the comparison, summarized by gap stratum and by mean absolute shift over all fixtures.
- Validation-tie integrity: all nine identifiers in every fixture must have validation accuracy exactly 0.80, and all eight A identifiers must have identical predictions and one shared semantic signature.
