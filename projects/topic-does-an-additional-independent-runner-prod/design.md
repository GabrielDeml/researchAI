# Experiment design: Topic Does an additional independent runner produce the same preflight and artifact-level outcome? _(auto-enqueued follow-up from topic-can-make-reproduce-be-run-from-a-fresh-iso)_

**Hypothesis:** Across 24 deterministic synthetic packages whose prose instructions ambiguously specify either the working directory, relative input root, or output destination, two fixed and reasonable runner interpretations will disagree on preflight or artifact outcome in at least 18 cases; after replacing each ambiguous instruction with an equivalent canonical machine-readable command and absolute role mapping, the same runners will agree on all 24 outcomes and artifact hashes.

## Summary
Generate 24 deterministic synthetic packages with ambiguous working-directory, input-root, or output-destination instructions, compare two fixed relative-path interpretations before and after replacing the prose with canonical absolute-path execution manifests, and measure outcome and artifact-hash agreement.

## Protocol
1. Use Python 3.11 or newer and install only matplotlib. Set the global seed constant to 20250308, set PYTHONHASHSEED=0 for every child process, and run child processes with LC_ALL=C and TZ=UTC. Do not access the network after dependency installation.
2. Create a fresh benchmark directory containing 24 independent sandboxes with IDs wd01-wd08, input01-input08, and output01-output08. Every sandbox must contain a package directory named package. All paths recorded in results must be relative to the sandbox root so that temporary-directory prefixes cannot affect comparisons.
3. Generate each CSV input with columns id,value and exactly 64 data rows. For package i, initialize random.Random(20250308+i), where i is the one-based package index from 1 through 24, and generate each value with randint(-10000,10000). Write CSV files with UTF-8 encoding, newline='\n', and rows id=0 through 63. When a distinct workspace-root input is required, copy the package input but replace every value v with v+100000+i. Thus the two candidate inputs have the same shape but necessarily different content.
4. Generate a deterministic task.py for every package. It must read the selected CSV, compute row_count, sum_value, min_value, max_value, and weighted_sum=sum((id+1)*value), and write artifact.json as compact sorted JSON using json.dumps(record, sort_keys=True, separators=(',',':')) followed by one newline. The record must also contain the SHA-256 hash of the exact input CSV bytes and the package ID, but no timestamps, absolute paths, host information, or random values. Use atomic output creation by making the parent directory and then writing the file. The script must return exit code 0 on success and nonzero on invalid arguments or unreadable input.
5. For wd01-wd08, make task.py take no arguments and always read data/input.csv and write results/artifact.json relative to its current working directory. The prose instruction.txt must be exactly: 'Run task.py from the supplied experiment files; it reads data/input.csv and writes results/artifact.json.' For wd01-wd04, create only package/data/input.csv. For wd05-wd08, create package/data/input.csv and sandbox-root data/input.csv, using the distinct transformed workspace input for the latter.
6. For input01-input08, make task.py accept required arguments --input-root and --output, read <input-root>/input.csv, and write exactly to --output. The prose instruction.txt must be exactly: 'Run package/task.py using data as the input root and write the result to the OUTPUT_ARTIFACT path supplied by the runner.' For input01-input04, create both package/data/input.csv and sandbox-root data/input.csv, with the latter using the transformed values. For input05-input08, create only package/data/input.csv. Define the runner-supplied OUTPUT_ARTIFACT path as the absolute path sandbox/outputs/artifact.json for both runners.
7. For output01-output08, make task.py accept required arguments --input and --output-dir, read --input, and write <output-dir>/artifact.json. Create only package/data/input.csv. The prose instruction.txt must be exactly: 'Run package/task.py with the supplied INPUT_FILE and place the result in results.' Define INPUT_FILE for both runners as the absolute path sandbox/package/data/input.csv.
8. Implement Runner A, named package-relative, with one fixed rule: every relative working directory, input path, and output path mentioned in prose is resolved against sandbox/package. For working-directory cases it executes the absolute task.py path with cwd=sandbox/package. For input cases it passes --input-root sandbox/package/data and the fixed absolute OUTPUT_ARTIFACT. For output cases it passes the fixed absolute INPUT_FILE and --output-dir sandbox/package/results.
9. Independently implement Runner B, named workspace-relative, with one fixed rule: every relative working directory, input path, and output path mentioned in prose is resolved against the sandbox root. For working-directory cases it executes sandbox/package/task.py with cwd=sandbox. For input cases it passes --input-root sandbox/data and the fixed absolute OUTPUT_ARTIFACT. For output cases it passes the fixed absolute INPUT_FILE and --output-dir sandbox/results. Neither runner may inspect the presence or content of candidate files to choose its interpretation.
10. Before executing a command, each runner must perform the same preflight checks in this order: cwd exists and is a directory; script exists and is a file; the interpreted input file exists and is a file; and the output parent can be created. Record the first failure as MISSING_CWD, MISSING_SCRIPT, MISSING_INPUT, or OUTPUT_PARENT_ERROR and do not execute after a failure. Otherwise run the task with subprocess.run, shell=False, a 10-second timeout, and the fixed environment. Record RUNTIME_ERROR for a nonzero exit and TIMEOUT for a timeout.
11. Run every ambiguous package once with each runner in separate, freshly copied sandboxes. After execution, create an outcome record containing status, preflight error code or null, exit code or null, and an artifact manifest. The artifact manifest is a sorted list of every artifact.json produced, with each entry containing its sandbox-relative POSIX path, byte count, and SHA-256 hash. A pair disagrees if its complete outcome records differ in status, error code, exit code, artifact path, artifact size, or artifact hash.
12. Replace instruction.txt in every package with protocol.json. Materialize all entries as absolute paths before execution. The JSON must contain schema_version=1, an absolute cwd, an argv array beginning with the absolute sys.executable and absolute task.py, and a roles object containing absolute paths for every input and output. For wd cases, set cwd to sandbox/package, use no script arguments, map input_file to sandbox/package/data/input.csv, and map output_artifact to sandbox/package/results/artifact.json. For input cases, set cwd to sandbox/package, pass --input-root sandbox/package/data and --output sandbox/outputs/artifact.json, and map those same paths as input_root and output_artifact. For output cases, set cwd to sandbox/package, pass --input sandbox/package/data/input.csv and --output-dir sandbox/package/results, and map input_file and output_dir to those same paths.
13. In canonical mode, both runners must use protocol.json verbatim after validating that argv, cwd, and every role path are absolute; they must not apply either relative-path rule. Run every canonical package with both runners in separate fresh copies, using the identical preflight, execution, and outcome-record procedure. Require an artifact from every canonical run.
14. Write results.json and results.csv with one row per package and mode, including both outcome records, disagreement indicators, statuses, artifact paths, and hashes. Compute counts and rates overall and separately for wd, input, and output categories.
15. Create disagreement_rates.png using matplotlib. Plot grouped bars for wd, input, output, and all packages, with one bar for ambiguous prose and one for canonical protocol. The y-axis must be disagreement rate from 0 to 1, each bar must be labeled with count/total, and a dashed horizontal line must mark 0.75, corresponding to 18 of 24.
16. Declare the hypothesis supported if and only if: at least 18 of 24 ambiguous-prose package pairs disagree; both canonical runners succeed on all 24 packages; all 24 canonical outcome records match pairwise; and the SHA-256 hashes of the canonical artifacts match pairwise in all 24 packages. Declare it refuted if any one of these conditions fails.

## Metrics
- Ambiguous outcome-disagreement count: number of the 24 ambiguous-prose packages whose complete Runner A and Runner B outcome records differ; the primary threshold is at least 18.
- Ambiguous disagreement rate: ambiguous outcome-disagreement count divided by 24, also reported separately for wd, input, and output groups using denominator 8 each.
- Preflight-disagreement count: number of package pairs in which status or preflight error code differs between runners.
- Artifact-manifest disagreement count: number of package pairs in which both runners succeed but artifact relative path, byte count, or SHA-256 hash differs.
- Artifact-hash disagreement count: number of package pairs in which both runners produce artifacts but the SHA-256 hashes differ.
- Canonical success count: number of canonical packages for which both runners succeed; it must equal 24.
- Canonical outcome-agreement count: number of canonical packages with identical complete outcome records between runners; it must equal 24.
- Canonical artifact-hash agreement count: number of canonical packages whose artifact SHA-256 hashes match between runners; it must equal 24.

## Time budget
20 minutes (ceiling 30).

## Expected outcomes
- **If supported:** At least 18 of 24 ambiguous-prose pairs disagree, while canonical execution yields 24 of 24 paired successes, 24 of 24 identical outcome records, and 24 of 24 matching artifact hashes. Under the specified fixtures, the expected ambiguous disagreement is 24 of 24: working-directory and input-root cases differ through preflight failures or input-dependent hashes, and output-destination cases differ through artifact paths.
- **If refuted:** The hypothesis is refuted if fewer than 18 ambiguous-prose pairs disagree, or if canonicalization leaves any runner failure, outcome mismatch, artifact-location mismatch, or artifact-hash mismatch in even one of the 24 packages.
