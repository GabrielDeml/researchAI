# Experiment design: Topic Can test generation, policy-equivalence checking, and canonicalization be separated so that an independently written parser and verifier validate every canonical archive? _(auto-enqueued follow-up from topic-can-the-original-executable-source-code-ex)_

**Hypothesis:** Among 30 seeded lossy canonicalizer mutants that delete, merge, truncate, or default a policy field while remaining deterministic, idempotent, and accepted by an independent parser, all 30 will pass structural acceptance and fixed-point checks, but exact finite-domain policy-equivalence checking will reject at least 27.

## Summary
Construct 128 finite-domain policies, canonicalize them with a correct baseline and 30 deterministic lossy mutants, then independently test parser acceptance, byte-level fixed points, exact policy equivalence, repeatability, and artifact completeness.

## Protocol
1. Use Python 3.11 or newer with only the standard library plus matplotlib. Set PYTHONHASHSEED=0 and use random.Random(20250308) for every randomized operation. Run without network access after dependency installation. Create separate modules named policy_generator.py, canonicalizers.py, independent_parser.py, independent_verifier.py, run_once.py, and run_experiment.py. independent_parser.py and independent_verifier.py must not import canonicalizers.py or call any canonicalization function; canonicalizers.py must not import either independent module.
2. Define an archive as UTF-8 JSON followed by exactly one newline. The top-level object is {"version":1,"policy":{...}}. Require policy_id as a string. Permit these optional policy fields: effect, subjects, actions, resources, time_slots, regions, min_clearance, require_mfa, and max_amount. Use universes subjects=["s0","s1","s2","s3"], actions=["a0","a1","a2","a3"], resources=["r0","r1","r2","r3"], time_slots=[0,1,2,3], regions=["g0","g1","g2","g3"], clearances=[0,1,2,3], MFA=[false,true], and amounts=[0,1,2,3]. Parser defaults for missing fields are effect="deny", each selector list equal to its complete four-element universe, min_clearance=0, require_mfa=false, and max_amount=3.
3. Implement independent_parser.py directly with json.loads and explicit validation. It must reject malformed JSON, extra top-level or policy keys, a version other than integer 1, missing/non-string policy_id, wrong types, duplicate list members, out-of-universe values, unsorted lists, and integers outside 0..3. It must accept empty selector lists and missing optional fields, applying the defaults in step 2. Do not reuse normalization, schema-validation, or serialization code from canonicalizers.py.
4. Define canonical byte serialization as json.dumps(obj, sort_keys=True, separators=(",",":"), ensure_ascii=False).encode("utf-8") + b"\n". Before serialization, sort and deduplicate every present selector list. Preserve missing optional fields rather than inserting defaults. C0 is the unmutated canonicalizer: it emits every field present in the generated source policy and otherwise only performs this normalization and serialization.
5. Generate exactly 128 source policies. Create the list 0..127, shuffle it once with random.Random(20250308), and let x be the shuffled value assigned to case T000 through T127. For bit(x,k) equal to bit k of x, set policy_id to the case ID, effect="allow", subjects=sorted({"s"+str(x%4), "s"+str((x+1+bit(x,0))%4)}), actions=sorted({"a"+str((x//4)%4), "a"+str(((x//4)+1+bit(x,1))%4)}), resources=sorted({"r"+str((x//16)%4), "r"+str(((x//16)+1+bit(x,2))%4)}), time_slots=sorted({x%4, (x+1+bit(x,3))%4}), regions=sorted({"g"+str((x//8)%4), "g"+str(((x//8)+1+bit(x,4))%4)}), min_clearance=1+(x%3), require_mfa=bool(bit(x,5)), and max_amount=x%3. Store x and the complete source policy in the per-case results.
6. Implement exactly 30 mutant canonicalizers. Each invocation first parses JSON internally with json.loads, normalizes present lists, applies its transformation, and canonically serializes without inserting missing fields. The catalog is: M01 delete subjects; M02 delete actions; M03 delete resources; M04 delete time_slots; M05 delete regions; M06 delete effect; M07 delete min_clearance; M08 delete require_mfa; M09 delete max_amount; M10 replace subjects by its lexicographically first member if nonempty; M11 similarly truncate actions; M12 similarly truncate resources; M13 replace time_slots by its minimum member if nonempty; M14 similarly truncate regions; M15 replace min_clearance v by 2*floor(v/2); M16 replace min_clearance by 0; M17 replace max_amount v by 1 when v is 0 or 1 and by 3 when v is 2 or 3; M18 replace max_amount by 3; M19 replace require_mfa by false; M20 replace effect by "deny"; M21 map subjects s1->s0 and s3->s2, leaving s0 and s2 fixed, then deduplicate; M22 apply the analogous a1->a0 and a3->a2 action map; M23 apply the analogous r1->r0 and r3->r2 resource map; M24 map time slots 1->0 and 3->2, leaving 0 and 2 fixed; M25 apply the analogous g1->g0 and g3->g2 region map; M26 intersect subjects with {"s0","s1"}; M27 intersect actions with {"a0","a1"}; M28 intersect resources with {"r0","r1"}; M29 intersect time_slots with {0,2}; and M30 intersect regions with {"g0","g1"}. Always sort transformed lists. Record this catalog verbatim in results.json.
7. Implement the semantic oracle independently in independent_verifier.py. Enumerate all 4*4*4*4*4*4*2*4=32768 requests in lexicographic product order over subject, action, resource, time_slot, region, clearance, require_mfa_value, and amount. A parsed policy matches when all five categorical values belong to their selector lists, clearance>=min_clearance, require_mfa is false or the request MFA value is true, and amount<=max_amount. Its decision is effect when it matches and "deny" otherwise. Represent the complete decision vector as a Python integer bitset with bit j=1 exactly when request j is allowed. Equivalence is exact integer equality; behavioral distance is (baseline_bitset XOR comparison_bitset).bit_count(). If unequal, decode and record the lowest-index differing request as a counterexample.
8. For every case, produce C0 bytes and perform exactly three baseline checks: independent parser acceptance, byte fixed point C0(C0(source_bytes))==C0(source_bytes), and exact equality between the source policy's semantic bitset and the independently parsed C0 archive's bitset. Record all three booleans, archive SHA-256, allowed-request count, and any error for each of the 128 cases. Aggregate each baseline count separately; all must equal 128.
9. For each mutant M01..M30 and each of the 128 C0 archives, compute y=M(C0_bytes) and z=M(y). Perform and record independent parser acceptance of y, byte fixed point y==z, exact semantic equivalence between parsed C0 and parsed y, behavioral distance, y SHA-256, byte lengths of C0 and y, and the first counterexample or null. This yields exactly 3840 mutant parser-acceptance checks, 3840 mutant byte-fixed-point checks, and 3840 mutant equivalence checks. A mutant is semantically rejected if at least one of its 128 cases has behavioral distance greater than zero.
10. For every mutant aggregate: accepted_case_count, fixed_point_case_count, equivalent_case_count, counterexample_case_count=128-equivalent_case_count, total_behavioral_distance=sum of the 128 distances, maximum_behavioral_distance, first failing case, and first counterexample. Also aggregate total mutant parser acceptances out of 3840, total fixed points out of 3840, total equivalent pairs out of 3840, and semantically_rejected_mutant_count out of 30.
11. Make run_once.py return a deterministic payload containing the seed, schema, universes, request-domain size, mutation catalog, all 128 source definitions, all C0 per-case results and aggregates, all 3840 mutant per-case results, all per-mutant aggregates, and chart values. Do not put timestamps, elapsed times, temporary paths, process IDs, or platform-specific values in this deterministic payload. Serialize it canonically and calculate its SHA-256.
12. In run_experiment.py, execute run_once.py twice in fresh subprocesses with PYTHONHASHSEED=0. Measure each subprocess using time.perf_counter. Require byte-for-byte equality of the two canonical deterministic payloads and equality of every archive SHA-256. Store repeat_run_equal, both payload SHA-256 values, each elapsed time, and total elapsed time in the final results. Use the first deterministic payload as the reported data.
13. Generate key_result.png with fixed size 14 by 7 inches and DPI 150. Plot mutant IDs M01..M30 on the x-axis. In the upper panel, plot accepted_case_count and fixed_point_case_count as grouped bars with a y-axis of 0..128. In the lower panel, plot counterexample_case_count as bars with a horizontal threshold line at 1 and a y-axis of 0..128. Use the noninteractive Agg backend, fixed colors, fixed labels, no current date, and metadata={"Software":"policy-equivalence-experiment"}. Store under chart_values the ordered mutant IDs and the three exact integer arrays used in the figure, plus semantically_rejected_mutant_count and the rejection threshold 27.
14. Build results.json with top-level keys schema_version, deterministic_payload, deterministic_payload_sha256, repeat_run, runtime, hypothesis_decision, chart_values, and artifact_manifest. hypothesis_decision must be "supported" exactly when all C0 acceptance, fixed-point, and equivalence counts are 128; mutant acceptance is 3840/3840; mutant fixed points are 3840/3840; semantically_rejected_mutant_count>=27; repeat_run_equal is true; and total elapsed time is at most 1800 seconds. Otherwise set it to "refuted" and list every failed condition.
15. Prevent another truncated export by writing results.json.tmp in UTF-8, flushing and calling os.fsync, then atomically replacing results.json with os.replace. Reopen results.json with json.load and assert that it contains 128 C0 records, 30 mutant records, exactly 128 case records under every mutant, 3840 mutant records in total, 30 values in every chart array, both run hashes, runtime fields, and a nonempty hypothesis decision. Write results.sha256 containing the SHA-256 of the completed results.json file. Add results.json, results.sha256, and key_result.png with byte sizes and SHA-256 hashes to artifact_manifest; because results.json cannot safely contain its own final hash, record its hash only in results.sha256 and record the manifest hash over the deterministic payload inside results.json. Exit nonzero if any validation or count assertion fails.
16. Keep the timed computation under 30 minutes. The exact verifier should use integer bitsets or precomputed request masks rather than storing millions of request dictionaries. Report total elapsed seconds and peak optional diagnostic memory if available, but runtime is the only required resource metric.

## Metrics
- C0 parser acceptance: number of the 128 baseline archives accepted by independent_parser.py; required value 128.
- C0 byte fixed points: number of cases satisfying C0(C0(source)) byte-for-byte equals C0(source); required value 128.
- C0 semantic preservation: number of source/C0 pairs with identical 32768-request decision bitsets; required value 128.
- Mutant structural acceptance: accepted mutant archives divided by 3840, with per-mutant and per-case results; the hypothesis requires 3840/3840.
- Mutant byte fixed points: mutant/case pairs satisfying M(M(C0(source))) byte-for-byte equals M(C0(source)), with per-mutant and per-case results; the hypothesis requires 3840/3840.
- Behavioral distance: XOR bit count between the C0 and mutant decision bitsets over all 32768 requests, reported per case and summed and maximized per mutant.
- Semantically rejected mutants: count of mutants having behavioral distance greater than zero for at least one of 128 cases; the support threshold is at least 27 of 30.
- Counterexample-case count: for each mutant, the number of its 128 cases with nonzero behavioral distance; these 30 integers are the key lower-panel chart values.
- Deterministic repeatability: byte-for-byte equality and matching SHA-256 of two complete deterministic payloads produced in fresh subprocesses; required value true.
- Artifact completeness: parsed record counts must be 128 C0 records, 30 mutant aggregates, 3840 mutant case records, and three chart arrays of length 30, with a successfully reparsed atomic results.json.
- Runtime: total wall-clock seconds for both fresh runs and artifact generation; required to be at most 1800 seconds.

## Time budget
30 minutes (ceiling 30).

## Expected outcomes
- **If supported:** C0 records 128/128 parser acceptances, 128/128 byte fixed points, and 128/128 exact semantic equivalences; mutants record 3840/3840 parser acceptances and 3840/3840 byte fixed points; at least 27 of the 30 mutants have one or more nonzero exact behavioral distances; repeat_run_equal is true; results.json passes all completeness assertions; key_result.png shows acceptance and fixed-point bars at 128 for every mutant while at least 27 counterexample bars exceed zero; and total runtime is at most 1800 seconds.
- **If refuted:** The hypothesis is refuted if mutant parser acceptance is below 3840, mutant byte fixed points are below 3840, 26 or fewer mutants are semantically rejected, or deterministic repeat-run equality fails. A C0 count below 128, an incomplete or invalid results.json, missing chart values, or runtime above 1800 seconds also forces a refuted decision because the claimed comparison was not validly reproduced.
